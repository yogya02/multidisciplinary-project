# Notebooks

Colab notebooks for each stage of the pipeline. Each member works in their own notebook and saves it here with **File → Save a copy in GitHub**.

## Naming convention
`NN_task_name.ipynb`, where NN is the pipeline order (for example `01_exploration.ipynb`).

## Rules
- Only edit your own notebook. Ask the owner before changing anyone else's.
- Write a clear commit message when saving, for example "added class-count chart".
- Do not commit the dataset or model files. They stay in Google Drive.
- Run the notebook from top to bottom before saving, to make sure it works.
